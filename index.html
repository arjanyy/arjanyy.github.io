Try my numerical analysis project

In my Numerical Analysis course I implemented the Steffensen root-finding method in Java. This is the same iteration running in your browser. It solves x² − c = 0, so the answer is √c. It stops when |f(x)| drops below 10⁻¹², and that last row turns red.
